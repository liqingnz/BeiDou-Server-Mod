# LK 移植 · 封存的脚本

这里放的是 **LichKingMod 里「把 BeiDou 已有 NPC 整个换掉」的脚本原文**。
它们在移植清单里判为 `rejected`，但内容有参考价值，所以留档而不是丢弃。

> **这个目录不在运行时路径上。** `NPCScriptManager` 只从
> `gms-server/scripts/npc/<npcid>.js` 与 `gms-server/scripts-zh-CN/npc/<npcid>.js` 取文件，
> 放在 `docs/` 下的副本不会被加载，也不会影响服务端行为。

---

## `npc/1022101.js` — LK 的枫叶兑换商

BeiDou 的 `1022101` 是 **Rooney，快乐村（209000000）传送 NPC**；LK 把它换成了四档兑换台。

**为什么没搬**

1. **Rooney 是快乐村唯一的入口，而且被放在 23 张地图里**（亨内西、魔法密林、勇士之村、
   射手村、维多利亚港、沉睡森林、圣地、里恩、天空之城、冰峰雪域、玩具城、欧米伽、
   韩国民俗村、神木村、武陵、清风谷、阿里安特、魔法密林、CBD、大都会、新叶城、
   蘑菇神社…）。其余碰 209000000 的 NPC（`9220005`、`2002000`）都在快乐村**里面**，
   是出口/返回；`9105005` 是雪人乐园，不相干。照搬 = 圣诞活动区整个失联，一次波及 23 张图。
2. **四档兑换的货币三档不存在**：

   | 货币 | 数据 | String.wz 名字 |
   |---|---|---|
   | `3100000` BOSS凭证 | ❌ 缺（`Item.wz/Install/0310.img.xml` 整个没有） | ✅ 有 |
   | `3100001` 组队凭证 | ❌ 缺（同上） | ✅ 有 |
   | `3101001` | ❌ 缺 | ❌ 缺 |
   | `4001126` 枫叶 | ✅ 有 | ✅ 有 |

   奖池里另有两把椅子 `3010121`、`3010135` 数据与名字皆缺。

**唯一自洽、值得将来单独捞出来的一块**：第三档「枫叶换职业武器」。
30 件武器（`1302020` 等）在 `Character.wz` 里**一件不缺**，货币 `4001126` 也有。
真要这个功能，做法是**挂到一个新 NPC 上**——找一个 `Npc.wz` 里有资源但没有地图放置的 ID，
像神木村扭蛋机（`9100111`）那样纯增量地加 `Map.wz` 放置——而不是拿快乐村的门去换。
这需要动 `Map.wz`，属第 6 项 wz 批次。

## `npc/9000036.js` — LK 的皇家点券兑换台

BeiDou 的 `9000036` 是亨内西的 **Agent E，饰品制作师**（坠子/脸部/眼部/勋章腰带/戒指，
各带材料配方与金币手续费）；LK 把它换成了皇家点券兑换台。

**为什么没搬**：用户 2026-08-17 决定**批次 8 皇家系统整批不做**。这份的五个菜单项依赖

| 依赖 | 现状 |
|---|---|
| `cm.gainRoyalPoint(n)` / `cm.gainRoyalTime(days)` | LK 加在 `AbstractPlayerInteraction` 上；BeiDou 全 Java 目录零处 royal |
| `@redeem` 指令 | 同属皇家系统 |
| 材料 `3100000` / `3100001` | 同上表，数据缺失 |
| 材料 `3101000` / `3101001` | 两层 `Item.wz` 都没有 |

只有 `5211900` / `5360900`（两个一小时点装）现成。只搬这两档等于拿一个能用的饰品制作 NPC
换一个五选一里四个是注释的空壳。

## `npc/9000036_accessory.js` — LK 留的饰品制作备份

LK 换掉 `9000036` 时把原饰品逻辑复制到了这个文件名下。**它在 LK 那边也是死文件**：
`NPCScriptManager` 按 `npc/<npcid>.js` 取文件，这个名字永远不会被加载，
LK 全仓库也没有任何 `openNpc(9000036, "9000036_accessory")` 调用（`git grep` 0 处）。
留档只为佐证「LK 确实是整个换掉、并未保留入口」这一判断。
BeiDou 现役的 `scripts/npc/9000036.js` 就是这份逻辑的英文原版，功能完好。

## 若将来重启

两处的共同教训：**不要照 LK 那样删掉原 NPC 来腾位置**。BeiDou 侧已经有一套更好的做法——
找 `Npc.wz` 里有资源但无地图放置的 ID，纯增量加 `Map.wz` 放置（见
`docs/lichkingmod-port.md` 里神木村扭蛋机 `9100111` 那一节）。两个 NPC 都能留着。
